# Brian Kiprono — Digital Marketing Portfolio

A responsive, single-page portfolio for Brian Kiprono, focused on Digital Marketing, Paid Media and Growth Marketing.

## Website

Enable GitHub Pages from **Settings → Pages** and select:
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

The site uses the profile photo and portfolio PDF hosted in the original `brian-kiprono-portfolio` repository.
